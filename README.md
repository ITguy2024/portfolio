# Joseph Nicolas Portfolio v2

## Before publishing
1. Open `index.html` and replace both instances of `YOUR_EMAIL@example.com` with your professional email.
2. Review the project labels. Apex and BrightSmile are currently described as **portfolio projects**; keep that wording unless they were actual client deployments.
3. The Custodial Operations Ticketing project is deliberately labeled **In Development**.
4. You can add a LinkedIn or OnlineJobs.ph button later if desired.

## Publish free on GitHub Pages
1. Create a public GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder.
3. Repository Settings → Pages → Deploy from a branch.
4. Select `main` and `/ (root)` and save.
5. Use the generated GitHub Pages URL in your OnlineJobs.ph Portfolio / Website field.
